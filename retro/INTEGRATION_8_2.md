# ASTATION RETRO 8.2 — Store & Mobile Performance

Install the free ASTATION RETRO system app in ASTATION OS Store. Its virtual SSD installation is explicitly simulated; downloading the actual DeSmuME core happens when launching an imported game. The application runs inside the ASTATION OS overlay, and previous profile data and ROM imports are preserved. No commercial ROMs or firmware are bundled.

Mobile default: DeSmuME 2015, frameskip 1, internal DS resolution 256x192, advanced timing off. Performance mode: frameskip 2. Quality mode: DeSmuME, higher resolution, frameskip 0. These are libretro options; they can improve speed on some phones but skipping rendering frames does not guarantee higher gameplay FPS. Test on physical iPhone is still needed.
