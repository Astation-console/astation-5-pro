# ASTATION 14.2 — Game theme music
Four original looping instrumental compositions: Sunny Steps, Midnight Signal, Islands of Light, Beyond the Rings. System: A New Horizon. Each is rendered with the browser's OfflineAudioContext from independent original note patterns, then played locally on the existing music bus. No Spotify media, copies, or remote music requests. Spotify discovery is a separate listening recommendation, not an integration license. Change selection via click, touch, keyboard or pad to change track regardless of wallpaper preference. Crossfade, mute, stop during gameplay or hidden tab, resume after exit. Test actual rendered PCM and selected-track state. Existing emulator and save storage untouched. No physical iPhone audio listening test.
